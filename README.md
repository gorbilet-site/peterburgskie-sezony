# Петербургские сезоны

Прототип концепта для Горбилета и Комитета по туризму Санкт-Петербурга.
Раздел о культурном туризме в низкий сезон — осень и зима.

## Запуск

Открыть `index.html` в браузере. Сборка не нужна, зависимостей нет.

## GitHub Pages

1. Создать репозиторий и загрузить содержимое этой папки в корень.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

## Структура

```
index.html          вся вёрстка, стили и скрипты в одном файле
assets/
  decor-bakst.jpg   фон первого экрана
  curtain.webp      занавес портала
  valance.webp      падуга для тёмных секций
  bakst-1..4.webp   эскизы костюмов для теста и разделов
  event-1..6.webp   фотографии событий
  route-map.webp    схема маршрута
  ambassador.webp   амбассадор премии
```

## Разделы

1. Первый экран — портал сцены, листалка «Ваш сезон».
2. Связь с «Русскими сезонами» Дягилева.
3. Тест на 30 секунд → персональный план поездки.
4. «Удиви меня, Петербург» — сценарий дня одной кнопкой.
5. «Ради чего стоит приехать» — афиша с фильтром по категориям.
6. «Лучшие маршруты сезона» — семь маршрутов с фактами и аудиогидами.
7. Народная театральная премия — голосование.

## Что заменить перед продакшеном

- **Фотографии событий** — `assets/event-*.webp` на реальные из каталога.
- **Схема маршрутов** — сейчас скриншот Яндекс.Карт, нужна лицензированная или своя отрисованная карта.
- **Логотипы в подвале** — сейчас нарисованы в разметке, подставить оригинальные файлы.
- **Фото амбассадора** — согласовать участие перед публикацией.
- **Данные** — массивы `EVENTS`, `ROUTES`, `SC` в конце `index.html` подключить к реальному API.

## Шрифты

Prata для заголовков, Inter для остального. Подключаются с Google Fonts.
